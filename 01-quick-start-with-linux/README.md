# Quick Start with Linux

This module covers the fundamental Linux concepts and commands needed to become comfortable working with the Linux terminal.

The lessons combine basic concepts with hands-on labs and challenges involving users, files, directories, permissions, ownership, and account management.

---

## 📚 Topics Covered

### 01 - Your First Linux Lab

Introduction to the Linux terminal and basic commands such as:

- `echo`
- `whoami`
- `id`

---

### 02 - Display User and Group Information

Understanding Linux user identity, including:

- User ID (UID)
- Group ID (GID)
- User groups
- Retrieving specific user information

---

### 03 - Basic File Operations

Working with files and directories using commands such as:

- `pwd`
- `ls`
- `cd`
- `touch`
- `mkdir`
- `cp`
- `mv`
- `rm`

---

### 04 - Files and Directories

Practicing file and directory management through hands-on exercises.

---

### 05 - File Contents and Comparing

Inspecting and comparing file contents using:

- `cat`
- `head`
- `tail`
- `diff`
- `diff -r`

---

### 06 - The Manuscript Mystery

A practical challenge focused on identifying differences between multiple versions of text files.

---

### 07 - Permissions of Files

Introduction to Linux permissions and access control using:

- `chmod`
- Numeric permissions
- Symbolic permissions
- Execute permissions

---

### 08 - Change File Ownership

Managing file and directory ownership using:

- `chown`
- Recursive ownership changes
- User and group ownership

---

### 09 - User Account Management

Managing Linux user accounts using:

- `useradd`
- `passwd`
- `usermod`
- `groups`
- `su`
- `userdel`

---

### 10 - The Joker's Trick

A final user-management challenge involving:

- Creating users
- Setting passwords
- Modifying user properties
- Changing shells and home directories
- Deleting users

---

## 🎯 Module Goals

By completing this module, I aim to:

- Become comfortable using the Linux terminal.
- Understand basic Linux filesystem operations.
- Manage files and directories.
- Understand file permissions and ownership.
- Manage Linux users and groups.
- Build a foundation for Linux system administration and DevOps.
